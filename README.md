# Axum Boilerplate

Initial workspace skeleton for an Axum boilerplate project in progress.

## Setup

1. `make setup`
2. `make up`
3. `make migrate`
4. `make seed`
5. `make dev`

## Commands

- `make setup`
- `make dev`
- `make up`
- `make down`
- `make reset-db`
- `make migrate`
- `make seed`
- `make fmt`
- `make lint`
- `make test`
- `make test-unit`
- `make test-integration`
- `make check`
- `make docs`
- `make ci`
- `make create-module name=billing`
